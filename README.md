# RPM（回転数で進める学習ノルマ）

## 1. 概要
教材のページ数（または問題数）・開始日・目標日・目標回転数を登録すると、今日やる量を表示する学習用Webアプリ。新しく進める分に加えて、エビングハウスの忘却曲線にもとづく間隔（1→3→7→14→30日後）で復習の分が出る。記録に合わせて毎日ノルマを組み直し、進み具合をモザイクタイルで表示する。

## 2. 必要な環境
- ブラウザ（iPhone の Safari、Android の Chrome、PC の Edge・Chrome など。2023年以降の版）
- Python・ライブラリのインストールは不要
- 開発・テストをする場合のみ: Node.js 20 以上、Python 3.11 以上（アイコン作成用）
- 端末間で同期する場合のみ: Firebase のプロジェクト（無料プランで可。下の「同期の準備」）

## 3. セットアップ手順

### 使う人
1. 公開URL（GitHub Pages）をブラウザで開く。
   ```
   https://takagawa-glitch.github.io/RPM/
   ```
2. iPhone では Safari の共有ボタン →「ホーム画面に追加」で、アプリのように使える。
3. スマホとPCで同じ記録を使いたい場合は、右上の「ログイン・同期」から、メールアドレスとパスワードで登録する。

### 公開する人（GitHub Pages）
1. GitHub のリポジトリの Settings → Pages を開く。
2. Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save。
3. 無料プランでは、リポジトリを Public にしないと Pages が使えない（Pro 以上なら Private のまま可）。Public にしても、見えるのはプログラムだけで、利用者の記録は見えない。

### 同期の準備（Firebase。管理者が1回だけ行う）
1. https://console.firebase.google.com/ でプロジェクトを作る（Google アナリティクスは不要）。
2. 「Authentication」→「始める」→ ログイン方法で「メール/パスワード」を有効にする。
3. 「Authentication」→「設定」→「承認済みドメイン」に `takagawa-glitch.github.io` を追加する。
4. 「Firestore Database」→「データベースを作成」→ ロケーションは `asia-northeast1`（東京）、本番環境モードで作成。
5. 「Firestore Database」→「ルール」に、このリポジトリの `firestore.rules` の中身を貼り付けて「公開」。
6. 「プロジェクトの設定」→「マイアプリ」→ ウェブアプリ（`</>`）を追加し、表示された `firebaseConfig` の値を `js/firebase-config.js` に貼り付けて、GitHub にプッシュする。

## 4. 実行方法
- 公開URLを開くだけ。
- 手元のPCで確認するとき（`index.html` をダブルクリックでは動かない。簡易サーバーが必要）:
  ```
  py -m http.server 8000
  ```
  ブラウザで `http://localhost:8000/` を開く。
- テスト:
  ```
  npm test
  ```
- アイコンを作り直す:
  ```
  py tools/make_icons.py
  ```

## 5. 設定できる項目

### アプリ全体（`js/firebase-config.js`）
| 名前 | 意味 | 既定値 | 必須 | 設定しないとき |
|---|---|---|---|---|
| firebaseConfig | Firebase の接続先（apiKey など） | 空 | 任意 | 同期の機能が出ず、端末の中だけで動く |

`apiKey` は Firebase の仕組み上、ブラウザに配る「識別子」で、パスワードではない。記録を守っているのは `firestore.rules`（本人しか読めない）。

### 教材ごと（画面で設定）
| 項目 | 意味 | 既定値 |
|---|---|---|
| 数える単位 | ページ／問題 | ページ |
| ページ数・問題数 | 1〜5000 | なし（必須） |
| 開始日・目標日 | 計画の期間 | 今日・90日後 |
| 目標の回転数 | 1ページを何回やるか（1〜10） | 5 |
| 復習の間隔（日） | 前回やった日から何日後に復習するか | 1,3,7,14,30 |

## 6. よくあるエラーと対処法
| 症状（画面のメッセージ） | 原因 | 対処 |
|---|---|---|
| 「読み込み中です…」のまま | 古いブラウザ／`index.html` を直接開いている | ブラウザを最新にする。公開URLから開く |
| 「同期の準備ができませんでした」 | インターネットにつながっていない | 通信を確かめて開き直す。その間は端末の記録で使える |
| 「メールアドレスかパスワードが違います」 | 入力ちがい | 入れ直す。忘れたら「パスワードを忘れた」 |
| 「保存できませんでした」 | 通信が切れている | 通信を確かめて、もう一度記録する |
| 「この端末に保存できませんでした」 | プライベートモード・ブラウザの保存領域が使えない | 通常モードで開く |
| 「バックアップファイルではないため、読み込めませんでした」 | 別のファイルを選んだ | 「ファイルに書き出す」で作った `RPM_バックアップ_日付.json` を選ぶ |

エラーの記録ファイル（error.log）はない（ブラウザで動くため）。解決しないときは、画面を撮影して作成者に知らせる。

## 7. 作られるファイル・データ
| 保存先 | 中身 | 個人情報 |
|---|---|---|
| 端末のブラウザの中（ログインしないとき） | 教材名・設定・学習記録 | 含まない（教材名に個人情報を書かないこと） |
| Firebase（ログインしたとき） | 上と同じ＋ログイン用メールアドレス | メールアドレスを含む |
| `RPM_バックアップ_日付.json`（書き出したとき） | 教材名・設定・学習記録 | 含まない |
